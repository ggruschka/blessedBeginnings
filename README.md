# Blessed Beginnings

Landing site for Blessed Beginnings — a Catholic children's products brand offering storybooks, heirloom toys, activity workbooks, and modest clothing.

## Tech Stack

React 19, TypeScript, Vite 8, Tailwind CSS 3, Motion (Framer Motion successor), shadcn/ui, Lucide icons.

## Development

```bash
npm install
npm run dev       # Start dev server
npm run build     # Typecheck + production build
npm run preview   # Serve production build locally
npm run lint      # ESLint
```
